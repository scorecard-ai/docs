---
title: "Model providers"
description: "Add your own model provider keys so AI metrics, prompts, and trace chat run on the models you choose."
---

Scorecard calls a language model to judge [AI metrics](/features/metrics#ai-metrics), to run [prompts](/features/prompts) in a Kickoff Run, and to answer questions in a record's **Chat** tab. If a metric's model has no provider key in your organization, Scorecard scores it with its default model.

## Add a provider key

1. Open **Settings → AI Providers**.
2. Click the pencil next to a provider and paste your key. AWS Bedrock also asks for a key ID, and Google Vertex AI for a project ID.
3. Click **Save Changes**.

| Provider | Models |
| --- | --- |
| OpenAI | GPT models |
| Anthropic | Claude models |
| Google | Gemini models through the Gemini API |
| Google Vertex AI | Gemini, and partner models such as Claude, through your Google Cloud project |
| AWS Bedrock | Models hosted in your AWS account, such as Claude and Llama |
| Groq | Open models served by Groq |

The provider's models then appear in every model picker, with recommended models listed first and **Show all models** for the rest. Delete a key with the trash icon.

## Add an Azure OpenAI deployment

Open **Settings → Custom Models** and click **Add Custom Model**. Choose **Azure OpenAI**, give it a label and your API key, and describe the deployment:

```json
{
  "model": "your_deployment_name",
  "api_base": "https://your-resource.openai.azure.com",
  "api_version": "2023-07-01-preview"
}
```

Custom models appear in model pickers under **Custom**.

## Data handling

Requests to a provider you've added use your key, so that provider's terms and data retention apply. See [Security and privacy](/features/security-and-privacy) for how Scorecard handles your data.
