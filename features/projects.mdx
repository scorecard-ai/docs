title: "Organizations and projects"
description: "How organizations, members, roles, projects, and API keys work in Scorecard."
---

An **organization** is your team's workspace. It holds your members, API keys, and model provider keys. Inside it, **projects** hold the records, testsets, metrics, runs, and systems for one agent or use case. Every member of an organization can open every project in it.

## Members and roles

Use the organization menu in the header to switch organizations, invite members, and change their roles. Scorecard has two roles:

| Role | Can |
| --- | --- |
| **Admin** | Everything a member can, plus: create API keys, assign records to reviewers, set reviewer aliases, and see every reviewer's scores, annotations, and the real system names in blind reviews |
| **Member** | Create and edit projects, testsets, metrics, prompts, and runs; score and annotate records |

Members see only their own grades and annotations, plus admins' and automated scores. See [What reviewers can see](/features/human-review#what-reviewers-can-see).

## Projects

Open the project selector in the header to switch projects or click **Create Project**. The setup wizard asks how data will arrive (a testset, traces, or the SDK) and suggests starting metrics. New organizations also get an **Example Project** with a sample agent, testset, metrics, and a scored run.

A project's ID is the number in its URL, for example `314` in `app.scorecard.io/projects/314/records`. You need it to route [traces](/features/tracing#route-traces-to-a-project) and to call the API.

- **Rename** a project by editing its name on the project's **Overview** page.
- **Delete** it from the **⋯** menu on the Overview page.
- **Move** testsets and metrics to another project with **Move to Project** in their menus.

### Project overview

The **Overview** page is a board of widgets you arrange: **Records analysis** for AI-found patterns in recent records, **Assigned to** for open review work, and a pass-rate widget for any metric. Click **Customize** to add, remove, resize, and reorder widgets, and use **Show records from** to set the time range for all of them. The layout is saved in your browser.

## API keys

Admins create keys under **Settings → Scorecard API Keys**. Each key starts with `ak_` and is shown once, so copy it to a secret manager right away. Every new organization also starts with a **Default API key**.

- Keys belong to the organization, not to a person, and act with admin permissions.
- Revoke a key from the same page. Revocation can take up to two minutes to apply everywhere.
- **Settings → Tracing URL** shows the OpenTelemetry endpoint for your account.
