## Which one should I use?

| If your agent uses | Use |
| --- | --- |
| The Claude Agent SDK, or you want to trace Claude Code itself | [Claude Agent SDK and Claude Code](/intro/claude-agent-sdk-tracing) |
| Claude in Slack | [Claude Tag](/intro/claude-tag-tracing) |
| Codex, Gemini CLI, OpenCode, or Goose | [Other coding agents](/integrations/coding-agents) |
| A framework such as LangChain, LangGraph, LlamaIndex, CrewAI, LiteLLM, or the OpenAI Agents SDK | [LangChain and other frameworks](/intro/langchain-quickstart) |
| The Vercel AI SDK | [Vercel AI SDK](/features/ai-sdk-wrapper) |
| The OpenAI or Anthropic SDK directly | [`wrap()`](/integrations/openai-anthropic) |
| Go, Java, .NET, Rust, Ruby, raw HTTP calls, or a hand-written agent loop | [OpenTelemetry](/integrations/opentelemetry) |
| An OpenAI-compatible client you can't change beyond its base URL | [LLM proxy](/integrations/openai-anthropic#llm-proxy) |

If your app uses a framework on top of a model SDK, trace the framework: it captures both layers.

See [Tracing](/features/tracing) for how Scorecard routes traces to projects, groups them into sessions, and reads tags and metadata.
