Claude Tag is [Claude working inside your team's Slack workspace](https://claude.com/docs/claude-tag/overview). Each session runs Claude Code in an Anthropic-hosted sandbox, so the same built-in OpenTelemetry tracing used for [Claude Agent SDK tracing](/intro/claude-agent-sdk-tracing) works here too—every Slack conversation with Claude lands in Scorecard as a full trace.

This quickstart shows how to configure an Anthropic-hosted environment so Claude Tag sessions are traced to Scorecard for observability, debugging, and evaluation.

<Info>
  Claude Tag requires a Claude **Team or Enterprise** plan, and these steps are done by a Claude organization admin. If your Slack workspace doesn't have Claude Tag yet, follow [Anthropic's setup guide](https://claude.com/docs/claude-tag/admins/setup-overview) first.
</Info>

## Steps

<Steps>
  <Step title="Create an Anthropic-hosted environment">
    Go to [**Cloud environments**](https://claude.ai/admin-settings/cloud-environments) in your Claude admin settings and create a new Anthropic-hosted environment (e.g. "Scorecard Tracing").

    In the **Environment variables** field, add the same variables used for Claude Agent SDK tracing, one per line as `KEY=value`. You'll need your Scorecard API key from [Settings](https://app.scorecard.io/settings).

    ```bash
    OTEL_EXPORTER_OTLP_HEADERS=Authorization=Bearer <your_scorecard_api_key>
    ENABLE_BETA_TRACING_DETAILED=1
    BETA_TRACING_ENDPOINT=https://tracing.scorecard.io/otel
    OTEL_LOG_USER_PROMPTS=1
    OTEL_LOG_TOOL_DETAILS=1
    OTEL_LOG_TOOL_CONTENT=1
    OTEL_RESOURCE_ATTRIBUTES=scorecard.project_id=<your-project-id>
    ```

    <DarkLightImage lightSrc="/images/claude-tag-create-environment.png" alt="Create an Anthropic-hosted environment dialog with name, network access, and environment variables fields" caption="Creating an Anthropic-hosted environment for Scorecard tracing." width="480" />

    <Note>
      Replace `<your_scorecard_api_key>` with your actual Scorecard API key (starts with `ak_`), and `<your-project-id>` with the project you want traces to land in. These variables are available to every session that uses this environment.
    </Note>

    <Warning>
      If the project ID is wrong or invalid, traces will be sent to the **oldest project** in your organization.
    </Warning>
  </Step>

  <Step title="Assign the environment to Claude Tag">
    Go to [**Claude Tag**](https://claude.ai/admin-settings/claude-tag) in admin settings and find **Claude Tag's access**. Select the **Slack** tab, expand **Advanced**, and set **Environment** to the environment you just created.

    <DarkLightImage lightSrc="/images/claude-tag-environment-setting.png" alt="Claude Tag's access page with the Slack tab selected, showing the Environment dropdown under Advanced" caption="Setting the environment under Claude Tag's access → Slack → Advanced." />

    <Note>
      Setting the environment on the Slack workspace applies it to all channels. You can also select an individual channel in the sidebar to scope it more narrowly.
    </Note>
  </Step>

  <Step title="Talk to Claude in Slack">
    Mention `@Claude` in a channel it's been invited to and give it a task. Every session Claude runs is now traced automatically—no changes needed on the Slack side.

    > @Claude summarize the open questions in this thread.
  </Step>

  <Step title="View traces in Scorecard">
    Navigate to the [**Records**](/features/records) page of your project in [Scorecard](https://app.scorecard.io). Each Claude Tag session appears as a record; click one to open its trace detail panel and see the full session—user turns, agent reasoning, and tool calls like Slack replies and reactions.

    <DarkLightImage lightSrc="/images/claude-tag-records-light.png" darkSrc="/images/claude-tag-records-dark.png" alt="Scorecard Records page showing Claude Tag sessions as records, with a trace detail panel displaying user turns and tool calls" caption="Claude Tag sessions arriving as records in Scorecard." />

    The trace detail panel breaks each session into four tabs: **Conversation**, **Timeline**, **Chat**, and **Debug**. See the [Claude Agent SDK tracing quickstart](/intro/claude-agent-sdk-tracing#steps) for a tour of each tab.
  </Step>
</Steps>
