## Evaluating

<AccordionGroup>
  <Accordion title="What's the difference between a run and a record?">
    A **record** is one execution of your agent: its inputs, outputs, and scores. A **run** is a batch of records, usually your agent's outputs on one testset, scored with the same metrics. Ten testcases scored with three metrics make one run, ten records, and thirty scores. See [Core concepts](/intro/concepts).
  </Accordion>
  <Accordion title="Does Scorecard score my production traces automatically?">
    Not by default. Traced records are stored as they arrive without scores. Select them on the [Records](/features/records) page and click **Score Records**, or give traces a shared `scorecard.tracing_group_id` so new ones are [scored automatically](/features/tracing#score-traces). To score new runs of your agent with their traces attached, use [`run_and_evaluate` with linked traces](/features/sdk-tracing).
  </Accordion>
  <Accordion title="How do I evaluate an agent that runs behind an HTTP API?">
    Call your API from the `system` function you pass to `run_and_evaluate`, and return the fields you want scored. See [Runs](/features/runs#run-from-code).
  </Accordion>
  <Accordion title="How do I evaluate multi-turn conversations?">
    Trace each turn with the same [session ID](/features/tracing#group-traces-into-sessions) to review a whole conversation as one record, or simulate conversations against your agent from code. See [Evaluate multi-turn conversations](/guides/multi-turn-conversations).
  </Accordion>
  <Accordion title="Can I use my own model as the judge?">
    Yes. Add a key for OpenAI, Anthropic, Google, Google Vertex AI, AWS Bedrock, or Groq, or an Azure OpenAI deployment, and pick the model on each AI metric. See [Model providers](/features/custom-provider).
  </Accordion>
  <Accordion title="Can I turn traces into testcases?">
    There's no button for it in the app. Export the records with **Export → Records**, or read them through the API, and create testcases from the inputs you want to keep with [the SDK](/features/testsets#manage-testsets-from-code). To mine a long agent session for test ideas, use [Import from transcript](/features/testsets#import-from-a-transcript).
  </Accordion>
  <Accordion title="What happened to the Playground, Custom Endpoints, and Sim Agents?">
    They were removed in September 2026. Test a prompt on a testset with a [Kickoff Run](/features/prompts#test-a-prompt-on-a-testset), evaluate an HTTP API by calling it from your [eval script](/features/runs#run-from-code), and simulate conversations [from code](/guides/multi-turn-conversations). Records those features created are still on the Records page.
  </Accordion>
</AccordionGroup>

## Integrations

<AccordionGroup>
  <Accordion title="Which languages and frameworks does Scorecard support?">
    Scorecard has Python and TypeScript SDKs and a REST API for everything else. Tracing accepts OpenTelemetry from any language, with guides for the Claude Agent SDK, Claude Code, the OpenAI and Anthropic SDKs, the Vercel AI SDK, LangChain, LlamaIndex, CrewAI, and more. See [Integrations](/integrations/overview).
  </Accordion>
  <Accordion title="Can my coding agent set Scorecard up for me?">
    Yes. Install [Scorecard's agent skills](/intro/ai-assisted-setup) and ask your agent to "Onboard this agent to Scorecard."
  </Accordion>
</AccordionGroup>

## Limits and data

<AccordionGroup>
  <Accordion title="What are the size limits?">
    Request bodies can be up to 5 MB, or 15 MB when creating records, and you can create up to 100 testcases per request. Attachments can be up to 100 MB each. See [API limits](/api-reference/overview#limits) and [tracing limits](/features/tracing#limits-and-privacy).
  </Accordion>
  <Accordion title="Are there rate limits?">
    Scorecard doesn't apply per-key rate limits. The SDKs retry throttled and failed requests automatically. Contact [support@scorecard.io](mailto:support@scorecard.io) before sending sustained high volumes.
  </Accordion>
  <Accordion title="Does Scorecard redact personal data?">
    No. Scorecard stores what you send. Redact personal data in your app before you export traces or create records, and turn off content capture in your instrumentation where you don't need it.
  </Accordion>
  <Accordion title="Is my data secure? Can Scorecard be self-hosted?">
    Scorecard is SOC 2 compliant and encrypts data in transit and at rest. For data-plane self-hosting or other specialized requirements, contact [team@scorecard.io](mailto:team@scorecard.io). See [Security and privacy](/features/security-and-privacy) and the [Trust Center](https://trust.scorecard.io).
  </Accordion>
</AccordionGroup>

## Billing

<AccordionGroup>
  <Accordion title="How does pricing work?">
    Plans are priced by the number of scores per month, with unlimited users. See [scorecard.io/pricing](https://www.scorecard.io/pricing) for current plans.
  </Accordion>
  <Accordion title="What counts as a score?">
    One metric's result on one record. Scoring 100 records with 2 metrics produces 200 scores.
  </Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
  <Accordion title="My traces don't show up">
    Check the API key, the project ID, and that short scripts flush before they exit. See [Tracing troubleshooting](/features/tracing#troubleshooting).
  </Accordion>
  <Accordion title="Scores are stuck as pending">
    Human metrics stay pending until a reviewer grades them. Members also see other reviewers' grades as pending, so a review can be further along than it looks. For AI metrics, open the record: if a score failed, its error explains why, for example a record too long for the judge model's context window. Fix the cause and re-score.
  </Accordion>
  <Accordion title="I can't create an API key">
    Only organization admins can create API keys. Ask an admin to create one for you.
  </Accordion>
</AccordionGroup>

Still stuck? Email [support@scorecard.io](mailto:support@scorecard.io) or check [status.scorecard.io](https://status.scorecard.io).
