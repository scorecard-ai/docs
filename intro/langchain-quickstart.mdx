[OpenLLMetry](https://github.com/traceloop/openllmetry) is an open-source set of OpenTelemetry instrumentations. One init call traces your framework and the model SDKs it calls, and Scorecard receives the traces. You don't need a Traceloop account.

It covers LangChain, LangGraph, LlamaIndex, CrewAI, Haystack, LiteLLM, and the OpenAI Agents SDK, along with OpenAI, Anthropic, AWS Bedrock, Google Gemini, Cohere, Mistral, and other providers. See the [OpenLLMetry repository](https://github.com/traceloop/openllmetry) for the full list.

## Install

<CodeGroup>
```bash Python
pip install traceloop-sdk
```

```bash TypeScript
npm install @traceloop/node-server-sdk
```
</CodeGroup>

The Python package includes the instrumentations for every library it supports.

## Initialize before your framework

Put this at the top of your entry point. Instrumentation patches libraries when they're imported, so call it **before** importing your framework or model SDK.

<CodeGroup>
```python Python
import os

from traceloop.sdk import Traceloop

os.environ.setdefault("TRACELOOP_METRICS_ENABLED", "false")  # Scorecard stores traces only

Traceloop.init(
    app_name="my-agent",
    api_endpoint="https://tracing.scorecard.io/otel",
    headers={"Authorization": f"Bearer {os.environ['SCORECARD_API_KEY']}"},
    resource_attributes={"scorecard.project_id": os.environ["SCORECARD_PROJECT_ID"]},
    disable_batch=True,
    telemetry_enabled=False,
)

# Import your framework after Traceloop.init
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_messages([("system", "You are a helpful assistant."), ("user", "{input}")])
chain = prompt | ChatOpenAI(model="gpt-4o-mini")
print(chain.invoke({"input": "What is the capital of France?"}).content)
```

```typescript TypeScript
import * as traceloop from "@traceloop/node-server-sdk";
import OpenAI from "openai";

// Set OTEL_RESOURCE_ATTRIBUTES=scorecard.project_id=<id> in the environment.
traceloop.initialize({
  appName: "my-agent",
  baseUrl: "https://tracing.scorecard.io/otel",
  headers: { Authorization: `Bearer ${process.env.SCORECARD_API_KEY}` },
  disableBatch: true,
  instrumentModules: { openAI: OpenAI },
});
```
</CodeGroup>

- `disable_batch` (`disableBatch`) sends each span right away, which short scripts need. Drop it for busy servers.
- `telemetry_enabled=False` turns off Traceloop's own anonymous usage reporting.
- In Python, leave out `instruments=` to trace every installed library, or pass a set such as `{Instruments.LANGCHAIN, Instruments.OPENAI}` to limit it.

In TypeScript, pass the modules to instrument, because ES modules and bundlers can hide them from automatic patching. Each key in `instrumentModules` takes a specific shape, and the wrong one crashes at startup:

| Key | Pass |
| --- | --- |
| `openAI` | The default export: `import OpenAI from "openai"` |
| `anthropic` | The module namespace: `import * as anthropic from "@anthropic-ai/sdk"` |
| `langchain` | The LangChain module namespaces, for example `{ chainsModule, agentsModule, toolsModule }` |
| `llamaIndex`, `bedrock`, `cohere` | The module namespace: `import * as x from "..."` |

## Verify

Run your app and open your project's **Records** page. Each chain or agent run appears as a record within a minute.

## Configure with environment variables

To keep the endpoint and key out of code, set them as environment variables instead. You still need the `Traceloop.init()` or `traceloop.initialize()` call.

```bash
export TRACELOOP_BASE_URL="https://tracing.scorecard.io/otel"
export TRACELOOP_HEADERS="Authorization=Bearer%20${SCORECARD_API_KEY}"
export TRACELOOP_METRICS_ENABLED=false
export OTEL_RESOURCE_ATTRIBUTES="scorecard.project_id=${SCORECARD_PROJECT_ID}"
```

Write the space in `TRACELOOP_HEADERS` as `%20`.

## Name your steps

Traceloop's decorators give agent steps readable names in the trace:

<CodeGroup>
```python Python
from traceloop.sdk.decorators import workflow


@workflow(name="answer_question")
def answer(question: str) -> str:
    ...
```

```typescript TypeScript
await traceloop.withWorkflow({ name: "answer_question" }, async () => {
  // agent code
});
```
</CodeGroup>

For one record per conversation, set a [session ID](/features/tracing#group-traces-into-sessions) on a span you open around each turn. Traceloop association properties aren't read as session IDs.

## What's captured

| Data | Description |
| --- | --- |
| Model calls | Prompts, completions, model, and token counts |
| Chains and workflows | Inputs, outputs, and intermediate steps |
| Agents and tools | Tool selections, inputs, and results |
| Retrievers | Retrieval calls and returned documents |
| Errors | Failed steps with their error |

## Troubleshooting

<AccordionGroup>
  <Accordion title="Nothing is traced">
    `Traceloop.init` ran after the framework was imported. Move it to the top of your entry point. If you load a `.env` file, load it before `Traceloop.init`.
  </Accordion>
  <Accordion title="Failed to export metrics batch: 404">
    Metrics export is on. Set `TRACELOOP_METRICS_ENABLED=false`. "Failed to export batch" warnings at shutdown are harmless when spans still arrive.
  </Accordion>
  <Accordion title="Traces land in the oldest project">
    Set `scorecard.project_id` as a resource attribute, through `resource_attributes` in Python or `OTEL_RESOURCE_ATTRIBUTES`.
  </Accordion>
  <Accordion title="I already send traces to Traceloop">
    To send to both, set up OpenTelemetry with two exporters. See [OpenTelemetry](/integrations/opentelemetry#add-scorecard-to-an-existing-setup).
  </Accordion>
</AccordionGroup>
