[Scorecard](https://www.scorecard.io) records what your AI agent does, scores it with metrics you define, and compares each new version with the last.

- **Trace** every model call, tool call, and conversation with OpenTelemetry, from Claude Code, LangChain, the Vercel AI SDK, or any language.
- **Score** records with AI judges, code checks, and human reviewers, using metrics you define or ready-made templates.
- **Evaluate** each version of your agent on a testset from code or CI, and compare results run over run.
- **Review** outputs as a team: assign records to reviewers and compare two outputs in a blind A/B review.

## Get started

Start with tracing if your agent already handles requests, or with evaluation if you want to test it on fixed inputs first.
