Create an API key in the [Scorecard app](https://app.scorecard.io/settings) under **Settings → Scorecard API Keys**. Only organization admins can create keys, and each key is shown once. New organizations also have a **Default API key**, which admins can copy from [app.scorecard.io/onboarding](https://app.scorecard.io/onboarding).

Your project ID is the number in the project's URL, for example `314` in `app.scorecard.io/projects/314/records`. New organizations start with an **Example Project** you can use.

```bash
export SCORECARD_API_KEY="ak_..."
export SCORECARD_PROJECT_ID="314"
```
